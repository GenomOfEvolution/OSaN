# Настройка адресного плана между эмуляторами

Запуск эмулятора происходит через запуск файла с расширением `.bat`  

## Первоначальная настройка каждого эмулятора  
Пояснение к началам строк:  
**">"**     - терминал обычного пользователя  
**"#"** - терминал суперпользователя  
**"(c)#"** - терминал конфига, который записывается как `hostname(config)#`  
**"(c-l)#"** - терминал конфига для линий(?), записывается как `hostname(config-line)#`  
**"(c-if)#"** - терминал конфига для интерфейсов(?), записывается как `hostname(config-if)#`  
```
> enable     //команда для входа в суперпользователя. Все настройки выполняются через него
# sh run       //команда для открытия файла запущенного конфига
# sh startup-config     //команда для открытия файла конфига(бэкапа?)
```

## Добавление пользователей и паролей
```
> en
# conf t                                //команда для настройки конфигурации
(c)# hostname r1                        //команда для настройки имени эмулятора(вместо r1 вставить необходимое)
(с)# service password-encryption        //команда для шифрования паролей
(с)# username <name> password 0 <pass>  //команда для создания пользователя с паролем. 0 означает, что пароль будет введен в незашифрованном виде
(с)# en password 0 <pass>              //команда для добавления пароля на суперпользователя
(с)# exit
# wr                                  //команда для сохранения конфигурации
```

Если хотите, чтобы пароль спрашивался не только при входе в суперпользователя, но и при входе в обычного пользователя:  
```
# conf t
(c)# line con 0
(c-l)# login local
(c-l)# exit
(c)# exit
# wr 
```

## Настройка эмуляторов
Необходимо настроить эмуляторы по схеме адресного плана. Обычно настраивается сначала тот интерфейс, кто будет пинговать, потом тот, кого будут пинговать.   
### Чтобы настроить "самого себя"  
```
# conf t
(c)# int <interface name>        //прописываем интерфейс, который будем настраивать(fa1/0 или fa0/0)
(c-if)# ip address <address> <mask>    //команда для добавления интерфейсу ip-адреса по его маске(например, если в адресе /30, то маска - 255.255.255.252)
(c-if)# duplec full   //команда, которая позволяет и принимать, и передавать
(c-if)# no shutdown   //команды настроек интерфейса
(c-if)# exit
(c)# exit
# wr
# ping <address>   //команда для проверки корректности настройки интерфейса - пинг настроенного адреса
//если вернется 5 пакетов с кодом "!" - "!!!!!", значит, все прошло успешно
```

### Чтобы проверить доступность другого адреса:
`# ping <ip-address>`  

### Посмотреть соседей(тех, кого пинговал)
`# sh cdp neighbors`

### Посмотреть все интерфейсы в эмуляторе(и свои, и которые пинговал)
`# sh arp`  

Не забывайте делать `wr` для сохранения конфигурации.  


## В итоге, краткая инструкция выполнения 1-го этапа настройки адресного плана:  
1. Зайти в r1 и настроить там пароли для пользователей, настроить fa1/0  
2. Зайти в r2 и настроить там пароли для пользователей, настроить fa0/0  
3. Вернуться в r1 и проверить пинг на r2  
4. Зайти в r2 и настроить fa1/0  
5. Зайти в r3 и настроить пароли для пользователей, настроить fa0/0  
6. Вернуться в r2 и проверить пинг на r3  
7. Зайти в r3 и настроить fa1/0  
8. Зайти в r4 и настроить пароли пользователей, настроить fa0/0  
9. Вернуться в r3 и проверить пинг на r4
